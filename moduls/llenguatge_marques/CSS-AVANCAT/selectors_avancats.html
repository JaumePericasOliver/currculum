Selectors avançats

Selectors d'atribut, combinadors, pseudoclasses (:hover, :nth-child, :first-of-type, :not) i pseudoelements (::before, ::after).

Progrés del bloc

2 / 11

Per què selectors avançats?

Els selectors bàsics (tipus, classe, id i universal) es queden curts en pàgines complexes. Els selectors avançats permeten triar elements amb molta més precisió: segons els seus atributs, la seva relació amb altres elements, el seu estat o la seva posició.

1. Selectors d'atribut

Seleccionen els elements que tenen un atribut concret o un valor d'atribut concret. Són especialment útils per donar estil als formularis o a elements amb atributs personalitzats.

Tipus de selector d'atribut
SelectorSelecciona els elements...
[atribut]que tenen l'atribut, amb qualsevol valor
[atribut="valor"]amb l'atribut exactament igual a valor
[atribut*="valor"]amb l'atribut que conté valor
[atribut^="valor"]amb l'atribut que comença per valor

Els noms d'atributs personalitzats han de començar per data- perquè l'HTML sigui vàlid.

2. Combinadors

Els combinadors seleccionen elements segons la seva relació amb altres elements dins del document.

Combinadors
SímbolNomExempleSelecciona

>Fill directediv > pNomés els p fills immediats d'un div

3. Pseudoclasses

Les pseudoclasses s'escriuen amb dos punts (:) i seleccionen un element quan és en un estat concret (per exemple, quan l'usuari hi passa el ratolí) o quan compleix una condició (per exemple, ser el primer del seu tipus).

:hover

Aplica estils quan l'usuari passa el ratolí per sobre de l'element.

:nth-child()

Selecciona elements segons la seva posició entre els seus germans. Entre parèntesis es pot posar un número (2 és el segon), o les paraules odd (senars) i even (parells).

Les taules d'aquests apunts fan servir tr:nth-child(odd) per pintar les files alternes.

:first-of-type

Selecciona el primer element del seu tipus dins del seu pare.

:not()

Selecciona tots els elements excepte els que coincideixen amb el selector entre parèntesis.

4. Pseudoelements

Els pseudoelements s'escriuen amb quatre punts (::) i donen estil a una part d'un element. Els més comuns són ::before i ::after, que afegeixen contingut abans o després del contingut real. Necessiten sempre la propietat content.

::before

::after

El contingut afegit amb content és decoratiu: no es pot seleccionar ni copiar, i molts lectors de pantalla l'ignoren. Mira el títol de cada apartat d'aquests apunts: la clau { del final és un ::after.

Bones pràctiques

  • Fes servir selectors d'atribut per als formularis: input[type="email"] evita haver de posar una classe a cada camp.
  • Prefereix > al combinador descendent quan vulguis afectar només un nivell: és més previsible.
  • No posis text important amb ::before o ::after: el contingut ha d'estar a l'HTML.
  • Evita cadenes de selectors massa llargues: són difícils de llegir i tenen una especificitat molt alta.
