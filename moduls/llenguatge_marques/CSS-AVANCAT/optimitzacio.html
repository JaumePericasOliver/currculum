Optimització i rendiment

Minificació, càrrega condicionada i asíncrona, compressió Gzip i Brotli, Autoprefixer, optimització de fonts i anàlisi amb DevTools.

Per què optimitzar el CSS?

Optimitzar el CSS garanteix que la pàgina es carregui ràpidament i funcioni bé en tots els dispositius, també els que tenen connexions lentes o poca potència, com molts mòbils. A més de millorar l'experiència de l'usuari, té un impacte positiu en el SEO i en la posició als cercadors.

1. Optimització dels fulls d'estil

a) Minificació del CSS

Consisteix a eliminar espais en blanc, salts de línia, comentaris i altres caràcters innecessaris per reduir la mida del fitxer i, per tant, el temps de càrrega. Es fa amb eines automàtiques com CSSNano o UglifyCSS.

Fixa't que el minificador també escurça els colors: #ffffff passa a #fff i #333333 a #333. El navegador entén exactament el mateix.

b) Càrrega condicionada del CSS

En un lloc web amb moltes pàgines, es pot carregar només el CSS que necessita cada pàgina o secció en lloc de tots els fulls d'estil alhora. L'atribut media de <link> accepta una media query.

contact.css només s'enllaça a la pàgina de contacte, i només s'aplica a pantalles de 768 píxels o més. El navegador el descarrega igualment, però amb prioritat baixa i sense aturar la visualització de la pàgina.

2. Compressió: Gzip i Brotli

A més de minificar, el servidor pot comprimir els fitxers abans d'enviar-los al navegador, normalment amb Gzip o Brotli. Es configura al servidor, no al CSS.

  • Redueix la mida del fitxer enviat al navegador.
  • Millora els temps de càrrega, especialment amb connexions lentes.

3. Càrrega asíncrona del CSS

Per defecte, el navegador no mostra la pàgina fins que ha carregat tots els fulls d'estil (el CSS bloqueja el renderitzat). Si carreguem de manera asíncrona el CSS que no és imprescindible, la pàgina es pot mostrar abans.

Amb media="none" el full d'estil es descarrega sense bloquejar la pàgina; quan s'ha carregat del tot, l'atribut onload canvia media a all i els estils s'apliquen. Fes-ho només amb el CSS secundari: si ho fas amb el principal, la pàgina es veurà un moment sense estils.

4. Autoprefixer

Els navegadors no sempre han admès les propietats noves de la mateixa manera. Durant anys, algunes només funcionaven amb un prefix de fabricant: -webkit- (Chrome, Safari), -moz- (Firefox), -ms- (Internet Explorer). Autoprefixer afegeix automàticament els prefixos necessaris perquè el CSS funcioni també en versions antigues dels navegadors.

El navegador es queda amb l'última declaració que entén. Pots provar-ho a Autoprefixer CSS online.

5. Optimització de fonts

Les fonts web poden ser una part important del pes d'una pàgina.

  • Formats optimitzats: WOFF i WOFF2 estan dissenyats per comprimir-se i descarregar-se ràpidament. Ho vam veure a l'apunt de tipografia.
  • Subconjunt de fonts (subsetting): si només fas servir uns quants caràcters d'una font, pots generar una versió reduïda que només els inclogui. Compte: en català necessites els accents, la ç i la l·l.
  • Només els gruixos necessaris: aquests apunts només carreguen IBM Plex Sans en 400 i 700.

6. Anàlisi del rendiment

Per optimitzar de debò, cal analitzar com es fa servir el CSS a la pàgina. Eines com Google Lighthouse, Chrome DevTools i CSS Stats ajuden a:

  • Detectar CSS no utilitzat i eliminar-lo per reduir la mida del full d'estil.
  • Identificar regles duplicades.
  • Auditar el rendiment: quins fulls d'estil retarden la càrrega de la pàgina.

Trobar CSS no utilitzat amb Chrome DevTools

  1. Obre Chrome DevTools (F12).
  2. Ves a la pestanya Coverage (Cobertura). Si no hi és, obre el menú ⋮ › More tools › Coverage.
  3. Recarrega la pàgina i mira quina part de cada fitxer CSS no s'està utilitzant (en vermell).

Prova-ho amb aquesta mateixa pàgina: veuràs que una part de apunts.css no s'utilitza aquí, perquè és per a elements que surten en altres apunts.

Bones pràctiques

  • Treballa amb el CSS llegible i comentat; minifica'l automàticament només per publicar.
  • Activa la compressió Gzip o Brotli al servidor.
  • Carrega de manera asíncrona només el CSS que no es veu en obrir la pàgina.
  • Revisa de tant en tant el CSS no utilitzat amb la pestanya Coverage.
