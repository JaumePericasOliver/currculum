UI i UX: dues cares del mateix disseny

Diferència entre UI i UX
UI (User Interface)UX (User Experience)
Què ésLa interfície d'usuari: el que l'usuari veuL'experiència d'usuari: com se sent fent-la servir
ObjectiuQue l'experiència visual sigui clara i atractivaQue l'usuari aconsegueixi els seus objectius de manera intuïtiva
ExempleEl color i la mida del botó de compraQuants passos calen per comprar

1. UI: interfície d'usuari

  • Principi de claredat: cada element de la interfície ha de tenir un propòsit clar. Evita elements innecessaris que distreguin l'usuari.
  • Contrast i jerarquia visual: fes servir el color i la mida per donar importància a les parts més destacades, com els botons d'acció o les seccions principals.
  • Feedback visual: els elements interactius (botons, formularis, enllaços) han de respondre quan l'usuari hi interactua, per exemple amb un canvi de color.
  • Microinteraccions: petites animacions en les interaccions, com botons que canvien de color o icones que es mouen, fan l'experiència més agradable.

La jerarquia és clara: el preu és el més gran, el nom va després i el detall és petit i gris. El botó és l'únic element de color fort, perquè és l'acció principal.

2. UX: experiència d'usuari

  • Coneixement de l'usuari: dissenya pensant en les necessitats i expectatives dels usuaris. En una botiga, per exemple, destaca els botons d'acció com "Afegir a la cistella".
  • Flux d'usuari: organitza els passos d'una tasca de manera clara. En un formulari de registre, posa primer els camps essencials i després les opcions addicionals.
  • Evitar friccions: simplifica processos com la navegació o la compra. Elimina passos innecessaris.
  • Adaptabilitat i responsivitat: molts usuaris arriben des de mòbils i tauletes; el contingut ha de ser fàcil d'utilitzar en pantalles petites.

3. Proves d'usabilitat

  • Feedback dels usuaris: recull opinions per entendre com interactuen amb el lloc i trobar punts de millora.
  • Tests A/B: prova dues versions d'un element o d'una pàgina per veure quina funciona millor.
  • Optimització contínua: la UX és un procés continu. A mesura que reculls informació, aplica-hi millores.

Bones pràctiques

  • Cada pantalla ha de tenir una acció principal clara i visualment destacada.
  • Tots els elements interactius han de canviar d'aspecte en passar-hi el ratolí: l'usuari ha de saber que s'hi pot fer clic.
  • Prova la teva pàgina amb persones reals: el que és evident per a tu no ho és per a tothom.
  • Pensa primer en el mòbil: si funciona en una pantalla petita, funcionarà a tot arreu.
