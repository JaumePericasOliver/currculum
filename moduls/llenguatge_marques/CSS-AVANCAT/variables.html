Variables CSS

Variables CSS (custom properties): com definir-les amb --nom, utilitzar-les amb var(), valors per defecte i avantatges en projectes grans.

Què són les variables CSS?

Les variables CSS, també anomenades custom properties (propietats personalitzades), permeten definir valors reutilitzables dins d'un full d'estil: colors, mides, espais, fonts...

Si has de canviar un d'aquests valors, només l'has de modificar en un lloc i el canvi es propaga a totes les regles que fan servir la variable.

1. Definir i utilitzar variables

  • Una variable es defineix dins de qualsevol selector amb un nom que comença per dos guions: --nom: valor;
  • Es fa servir amb la funció var(): propietat: var(--nom);
  • És habitual definir-les al selector :root (l'element arrel, <html>) perquè estiguin disponibles a tot el document.

Les variables s'hereten: una variable definida en un element està disponible per a tots els seus descendents. Per això, si la defineixes a :root, la pots fer servir a tota la pàgina. En els exemples d'aquest apunt les definim al contenidor de cada exemple perquè no afectin la resta de la pàgina.

Els noms distingeixen majúscules i minúscules: --Color i --color són dues variables diferents.

2. Avantatges en projectes grans

En projectes grans cal garantir que colors, mides i fonts siguin coherents. Canviar aquests valors a mà en molts llocs és lent i provoca errors; les variables els centralitzen.

Avantatges de les variables
AvantatgeQuè vol dir
MantenibilitatCanviant una sola variable es modifiquen valors globals com els colors o les mides.
ReutilitzacióLa mateixa variable es pot fer servir a qualsevol lloc del full d'estil.
ConsistènciaTots els elements que depenen d'una variable tenen exactament el mateix estil.

3. Valors per defecte

La funció var() accepta un segon valor, separat per una coma, que s'utilitza si la variable no està definida. Així el disseny funciona encara que la variable falti.

Bones pràctiques

  • Defineix les variables globals a :root, al principi del full d'estil.
  • Posa noms que expliquin la funció (--color-primari, --marge-general), no el valor (--blau, --deu-pixels).
  • Afegeix un valor per defecte a var() quan la variable pugui faltar.
  • No posis tots els valors en variables: només els que es repeteixen o que voldràs canviar.
