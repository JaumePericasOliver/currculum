Layouts amb Flexbox i Grid

Flexbox avançat (flex-shrink i align-self), CSS Grid (grid-template-columns, grid-template-rows, grid-column, grid-row i gap) i com combinar-los.

Flexbox o Grid?

Flexbox i CSS Grid són les dues eines més potents del CSS per crear dissenys flexibles, adaptables i organitzats. No competeixen: cada una és millor en una situació.

Quan fer servir cada eina
Flexbox (una dimensió)Grid (dues dimensions)
Alinear elements en una fila o una columna: botons d'una barra de navegació, imatges d'una galeria. Pàgines amb una estructura complexa: capçalera, barra lateral, contingut principal i peu.
Repartir l'espai entre els elements d'una fila (centrar-los o espaiar-los uniformement). Dissenys en quadrícula amb files i columnes: un tauler de fotos o un catàleg de productes.
Elements que han de créixer o encongir-se per omplir l'espai: una barra lateral, una fila de targetes. Controlar exactament a quina cel·la de la quadrícula va cada element.

1. Flexbox avançat

A l'apunt de Flexbox bàsic vam veure display: flex, flex-direction, justify-content, align-items i flex-grow. Ara hi afegim dues propietats que s'apliquen als elements fills.

flex-shrink

És el contrari de flex-grow: controla quant s'encongeix un element quan no hi ha prou espai. El valor per defecte és 1; com més gran, més s'encongeix; amb 0 l'element no s'encongeix mai.

El número de cada caixa és el seu flex-shrink. L'element vermell (0) manté el seu 40%; el que té flex-shrink: 3 s'encongeix tres vegades més que el primer.

align-self

Permet que un sol element tingui una alineació diferent de la que marca align-items al contenidor. Accepta els mateixos valors: flex-start, flex-end, center, baseline o stretch.

2. CSS Grid: quadrícules

CSS Grid Layout crea dissenys en dues dimensions (files i columnes) alhora. Permet col·locar els elements en una quadrícula amb molta precisió, controlant la mida de les files i les columnes.

Propietats clau de Grid
PropietatS'aplica aFunció
display: gridContenidorActiva Grid
grid-template-columnsContenidorNombre i mida de les columnes
grid-template-rowsContenidorNombre i mida de les files
gapContenidorEspai entre files i columnes
grid-columnElement fillQuantes columnes ocupa (span 2)
grid-rowElement fillQuantes files ocupa

La unitat fr (fracció) reparteix l'espai disponible: 1fr 2fr 1fr fa tres columnes on la del mig és el doble d'ampla que les altres.

A codi antic trobaràs grid-gap: és el nom antic de gap i fa el mateix.

3. Flexbox i Grid combinats

Sovint el millor és combinar-los: Grid per a la disposició general de la pàgina (files i columnes) i Flexbox dins d'algunes cel·les per alinear-ne el contingut. A l'exemple, la quadrícula té dues columnes, i la segona cel·la és alhora un contenidor flex que alinea els seus elements en fila.

Aquests apunts fan el mateix: la capçalera del lloc és una quadrícula i, a dins, el menú és una altra quadrícula en mòbil i una fila flex en pantalles grans.

Bones pràctiques

  • Pregunta't si el disseny és d'una dimensió (Flexbox) o de dues (Grid) abans de triar.
  • Fes servir la unitat fr en lloc de percentatges a Grid: té en compte el gap i no desborda.
  • Posa flex-shrink: 0 als elements que no s'han de deformar, com icones o imatges petites.
  • Combina Grid i media queries: canviant només grid-template-columns pots passar de tres columnes a una en mòbil.
