CSS avançat: introducció

Per què cal un CSS avançat: disseny adaptable i optimitzat, i bones pràctiques d'organització del CSS en projectes grans.

Progrés del bloc

1 / 11

Del CSS bàsic al CSS avançat

A mesura que els projectes web es tornen més complexos, el CSS també ha d'evolucionar. El CSS avançat no només busca una pàgina atractiva: també vol que la pàgina funcioni bé en tots els dispositius, que sigui fàcil de mantenir i que estigui optimitzada per carregar ràpid.

Disseny adaptable i optimitzat

Un dels pilars del CSS avançat és el disseny responsiu, que permet que les pàgines s'adaptin a diferents mides de pantalla. És cada vegada més important a causa de l'augment de l'ús de dispositius mòbils. Per aconseguir-ho, el CSS avançat combina tres tècniques:

  1. Media queries avançades: diverses condicions i punts de tall per adaptar el disseny.
  2. Unitats relatives i flexibles: %, em, rem, vw, vh i fr en lloc de mides fixes en píxels.
  3. Layouts responsius amb Flexbox i Grid: sistemes de disseny que reparteixen l'espai automàticament.

Organització del CSS en projectes grans

Quan el projecte creix, cal mantenir el codi CSS ordenat perquè no es torni impossible de gestionar.

1. Modularització

  • Dividir el CSS en fitxers petits i temàtics (tipografia, capçalera, formularis...).
  • Seguir una arquitectura CSS escalable, com SMACSS o BEM, que estableixen normes per organitzar i anomenar les classes.

2. Preprocessadors CSS

Eines com Sass o LESS amplien el llenguatge (variables, anidament, funcions...) i després generen un fitxer CSS normal que entén el navegador.

3. Optimització

  • Minificació: eliminar espais, salts de línia i comentaris per reduir la mida del fitxer.
  • Càrrega asíncrona: carregar el CSS no imprescindible sense bloquejar la visualització de la pàgina.

4. Frameworks CSS

Els frameworks ofereixen estils i components ja fets per accelerar el desenvolupament. Els més coneguts són Bootstrap i Tailwind CSS.

Continguts d'aquest bloc

  1. Selectors avançats: d'atribut, combinadors, pseudoclasses i pseudoelements.
  2. Fonts i tipografia avançades: @font-face, WOFF i control fi del text.
  3. Layouts amb Flexbox i Grid: Flexbox avançat, CSS Grid i com combinar-los.
  4. Popover API: contingut emergent natiu amb HTML i CSS, sense JavaScript.
  5. Variables CSS: valors reutilitzables amb --nom i var().
  6. Animacions i transicions: transition, @keyframes i animation.
  7. Disseny atractiu i coherent: consistència, navegació, llegibilitat i càrrega.
  8. UI/UX: interfície d'usuari, experiència d'usuari i proves d'usabilitat.
  9. Optimització i rendiment: minificació, compressió, càrrega asíncrona, Autoprefixer i fonts.
  10. Eines modernes de CSS: Sass, LESS, Bootstrap 5 i Tailwind CSS.

Bones pràctiques

  • Abans de començar un projecte, decideix com organitzaràs els fitxers i com anomenaràs les classes.
  • Treballa amb el CSS llegible i comentat; minifica'l només per publicar-lo.
  • Aprèn bé el CSS abans d'utilitzar un framework: així entendràs què fa i el podràs adaptar.
