Eines modernes de CSS

Els preprocessadors Sass i LESS (variables, nesting, mixins, herència, control i operacions) i els frameworks Bootstrap 5 i Tailwind CSS.

Què són les eines modernes de CSS?

Són eines que faciliten i milloren la manera de treballar amb CSS: permeten escriure'l de manera més eficient, modular i escalable. En veurem de dos tipus:

Tipus d'eines
TipusQuè faExemples
PreprocessadorAmplia el llenguatge (variables, anidament, funcions...) i compila el resultat a CSS normal.Sass, LESS
FrameworkOfereix estils i classes ja fets per construir pàgines ràpidament.Bootstrap, Tailwind CSS

Sass (Syntactically Awesome Style Sheets)

Sass és un preprocessador CSS que hi afegeix variables, anidament (nesting), mixins, funcions i herència. El navegador no entén Sass: cal compilar-lo a un fitxer CSS normal.

Instal·lar i compilar Sass

Més informació a sass-lang.com.

Dues sintaxis: .sass i .scss

Sass té dues sintaxis que compilen exactament al mateix CSS:

Quina sintaxi triar?
Tria SCSS si...Tria Sass si...
Prefereixes una sintaxi semblant al CSS tradicional.Prefereixes una sintaxi més neta i minimalista.
Treballes amb un equip que fa servir CSS estàndard.Vols escriure menys caràcters.
Vols que qualsevol fitxer CSS sigui també SCSS vàlid.

Avui dia SCSS és la sintaxi predeterminada i la més utilitzada. Els exemples següents la fan servir.

Variables

Es defineixen amb $. A diferència de les variables CSS, només existeixen mentre es compila: al CSS final se substitueixen pel seu valor.

Nesting (anidament)

Permet escriure el CSS en una estructura jeràrquica que reflecteix l'HTML.

list-style: none treu les vinyetes d'una llista i text-decoration: none treu el subratllat dels enllaços.

Mixins

Blocs de codi reutilitzables que poden rebre paràmetres. Es defineixen amb @mixin i s'utilitzen amb @include.

Herència (@extend)

Permet reutilitzar els estils d'un selector en altres. Un selector que comença per % és un placeholder: no apareix al CSS final si no s'estén.

Control: condicions i bucles

Sass permet afegir lògica: @if / @else i bucles com @for. Aquest exemple genera quatre classes, .column-1 a .column-4.

A les versions actuals de Sass, la divisió amb / (100% / $i) està en desús: s'ha d'escriure math.div(100%, $i) després d'importar el mòdul amb @use "sass:math";.

Avantatges de Sass

  • Organització: variables i anidament mantenen el codi ordenat.
  • Reutilització: mixins i herència eviten repeticions.
  • Escalabilitat: ideal per a projectes grans, perquè permet dividir el CSS en molts fitxers.
  • Compatibilitat: compila a CSS estàndard, que funciona a tots els navegadors.

LESS (Leaner Style Sheets)

LESS és un altre preprocessador amb variables, mixins, funcions i anidament. Va ser un dels primers a fer-se popular.

Variables

Es defineixen amb el símbol @.

Mixins

Un mixin es defineix com si fos una classe i es "crida" com una funció.

Anidament i operacions

Com Sass, permet escriure estils dins d'altres estils. A més, permet fer operacions matemàtiques.

Bootstrap 5

Bootstrap 5 és un framework de front-end per crear llocs web responsius i atractius sense escriure gaire CSS ni JavaScript, gràcies a les seves classes i components predefinits.

1. Sistema de graella (grid system)

  • Estructura responsiva: dissenys que s'adapten a mòbils, tauletes i ordinadors.
  • Basat en Flexbox (des de Bootstrap 4).
  • Punts de ruptura (breakpoints): classes per a cada mida de dispositiu: xs, sm, md, lg, xl i xxl.

Aquest resultat està fet amb Flexbox per no carregar Bootstrap en aquests apunts: .row és un contenidor flex i cada .col té flex-grow per repartir-se l'espai, que és com funciona Bootstrap per dins.

2. Responsivitat integrada

Tots els components i utilitats estan pensats per ser responsius i fan servir media queries per adaptar-se a cada mida de pantalla.

3. Components predefinits

Alguns components de Bootstrap
ComponentPer a què serveix
navbarBarres de navegació personalitzables i adaptables
btnBotons amb estils i estats (actiu, desactivat...)
cardTargetes amb títol, text, imatges i botons

4. Utilitats CSS

  • Text: classes per a la mida, l'alineació i el color del text.
  • Espais: m-3 (marge), p-2 (farcit)...
  • Colors: text-primary, bg-secondary...

5. Personalització i documentació

Bootstrap es pot personalitzar amb Sass i amb variables CSS (colors, fonts, mides) i té temes predefinits. La seva documentació és molt completa, amb exemples per començar fàcilment.

Instal·lació

  1. CDN (Content Delivery Network): el mètode més ràpid. No cal descarregar res, només afegir un enllaç a l'HTML.
  2. Descàrrega local: descarregues els fitxers CSS i JS i els afegeixes al projecte.
  3. npm: recomanat per a projectes grans o amb frameworks com React, Angular o Vue.

Tailwind CSS

Tailwind CSS és un framework utilitari (utility-first): en lloc de components ja fets (com Bootstrap), ofereix moltes classes petites, cada una amb una sola funció (un color, un marge, una mida de lletra...), que es combinen directament a l'HTML per construir dissenys únics.

Cada classe fa una cosa: bg-blue-500 (color de fons), text-white (color del text), px-4 i py-2 (farcit horitzontal i vertical), rounded (cantons arrodonits) i md:text-lg (text més gran a partir de pantalles mitjanes).

Característiques

  1. Classes basades en utilitats: cada classe fa una única funció.
  2. Altament personalitzable: el fitxer de configuració tailwind.config.js permet ajustar paletes de colors, tipografies, punts de ruptura i espais.
  3. Disseny responsiu senzill: classes amb el prefix del punt de ruptura (sm:, md:, lg:...).
  4. Escales predefinides per a l'uniformitat del disseny: espais (p-0 a p-12; p-4 = 1rem, m-2 = 0.5rem), text (text-xs, text-sm, text-lg, text-xl...).
  5. Paleta de colors extensa, amb nivells d'intensitat del 50 al 900: bg-red-500, text-blue-400.
  6. Control complet: no hi ha botons ni targetes predefinits; tu els construeixes.
  7. CSS mínim: en producció elimina automàticament les classes que no fas servir, i el fitxer final és molt petit.
  8. Flexbox i Grid integrats: classes com flex, grid o justify-center.
  9. Components reutilitzables amb la directiva @apply, que agrupa diverses utilitats en una classe teva.
  10. Documentació i comunitat: documentació clara a tailwindcss.com i moltes plantilles de la comunitat.

Bones pràctiques

  • Aprèn bé el CSS abans de fer servir un preprocessador o un framework: tot acaba sent CSS.
  • No aniuis més de tres nivells amb Sass o LESS: el CSS generat té selectors massa llargs.
  • Per a projectes nous, les variables CSS natives ja cobreixen molts casos que abans requerien un preprocessador.
  • Tria un sol framework per projecte i no barregis Bootstrap i Tailwind.
