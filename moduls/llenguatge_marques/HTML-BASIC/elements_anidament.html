Elements HTML i anidament

HTML bàsic · Diferència entre etiqueta i element HTML, i com s'aniden correctament els elements.

Diferència entre etiquetes i elements

Etiqueta i element en HTML
Concepte Etiqueta (tag) Element
Definició És la part que defineix l'inici i el final d'un component en HTML. Inclou l'etiqueta d'obertura, el contingut (si n'hi ha) i l'etiqueta de tancament.
Característiques Es delimita amb els símbols < >. Els elements poden ser buits o contenir altres elements dins.
Exemples <p>, </p>, <h1>, </h1> <p>Aquest és un paràgraf.</p>

Elements anidats

Anidament es refereix a col·locar un element HTML dins d'un altre element.

És important seguir correctament l'ordre de les etiquetes: la primera que s'obre és l'última que es tanca.
