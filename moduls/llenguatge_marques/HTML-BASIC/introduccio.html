Introducció a HTML

HTML bàsic · Què és HTML i breu història del llenguatge de marques per crear pàgines web.

Què és HTML?

  • HTML (HyperText Markup Language) és el llenguatge de marques per crear pàgines web.
  • Defineix l'estructura de la pàgina amb etiquetes que el navegador interpreta per mostrar contingut.

Breu història

  1. Creat per Tim Berners-Lee el 1991.
  2. HTML 2.0 (1995): primer estàndard oficial.
  3. HTML5 (2014): última versió, amb noves funcionalitats com suport per a vídeo, àudio i gràfics.
