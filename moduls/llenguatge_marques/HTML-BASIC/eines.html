Eines inicials

HTML bàsic · Editors de codi per començar amb HTML: Notepad++ i Sublime Text.

Notepad++

Notepad++ és un editor de codi font i un substitut del Bloc de notes que és totalment gratuït i compatible amb diversos llenguatges de programació.

Característiques principals

  • Gratuït i codi obert: el seu ús es regeix per la Llicència Pública General GNU (GNU General Public License).
  • Base potent: està construït sobre el component d'edició Scintilla.
  • Rendiment elevat: està escrit en C++ i utilitza l'API pura de Win32 i STL, cosa que assegura alta velocitat i una mida de programa reduïda.
  • Consciència ecològica: optimitzant les rutines per utilitzar menys CPU, contribueix a reduir les emissions de diòxid de carboni.
  • Entorn d'execució: funciona principalment en sistemes MS Windows.

En resum, és una eina popular i ràpida per a qualsevol persona que necessiti un editor de text més avançat que el Bloc de notes.

Sublime Text

Sublime Text és un editor de codi lleuger i multiplataforma (Windows, macOS, Linux) orientat a la velocitat i l'eficiència. El nucli és en C++ i té una API de connectors en Python.

  • Funcions clau: Goto Anything, Command Palette, cursors múltiples i seleccions en columna, mode Distraction Free, minimapa, edició en panells, cerca i reemplaçament amb expressions regulars a tot el projecte, fragments (snippets) i macros, build systems configurables i integració LSP mitjançant paquets.
  • Ecosistema: extensible mitjançant paquets gestionats habitualment amb Package Control.
  • Llicència: comercial amb prova indefinida; programari tancat.
  • Punts forts: molt ràpid, consum baix, estable amb fitxers grans i alt nivell de personalització (dreceres de teclat, temes, fragments).
