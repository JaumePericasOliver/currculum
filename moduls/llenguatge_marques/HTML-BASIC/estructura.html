Estructura bàsica d'un document HTML

HTML bàsic · Estructura jeràrquica d'un document HTML: DOCTYPE, html, head i body.

Estructura general

  1. Un document HTML es basa en una estructura jeràrquica d'etiquetes que defineixen les diferents parts d'una pàgina.
  2. Cada pàgina HTML segueix una estructura similar, començant pel <!DOCTYPE>, seguit de les etiquetes <html>, <head> i <body>.

Les parts del document

  • <!DOCTYPE html>: indica al navegador que el document és HTML5.
  • <html>: element arrel que conté tot el document.
  • <head>: capçalera amb informació sobre el document (títol, metadades). No es mostra a la pàgina.
  • <body>: cos amb el contingut visible de la pàgina.

Consulta les metadades en HTML per completar el <head> correctament.
