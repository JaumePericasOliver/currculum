Atributs HTML

HTML bàsic · Què són els atributs HTML i com s'escriuen amb el format nom=valor.

Què són els atributs?

Els atributs en HTML afegeixen informació extra a les etiquetes HTML per modificar-ne el comportament o l'aparença.

Aquests atributs sempre es col·loquen dins de l'etiqueta d'obertura i segueixen el format nom="valor".
