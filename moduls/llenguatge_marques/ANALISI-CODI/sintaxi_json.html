Sintaxi de JSON

Anàlisi de codi · Estructura i regles sintàctiques de JSON, problemes dels documents mal formats i alternatives als espais de noms.

Estructura

El JSON (JavaScript Object Notation) és un format lleuger per emmagatzemar i intercanviar dades, especialment utilitzat en aplicacions web.

Regles sintàctiques

  • Les claus i les cadenes de text han d'estar entre cometes dobles (" ").
  • Els elements han d'estar separats per comes.
  • Els objectes es defineixen amb claus ({}) i les llistes amb claudàtors ([]).

Problemes dels documents mal formats

Si un document JSON està mal format, les aplicacions no podran carregar ni processar les dades.

Conseqüència: falta una coma després de "Joan López", la qual cosa provocarà un error de sintaxi en intentar carregar les dades.

Espais de noms

El JSON no utilitza espais de noms com l'XML, però els objectes en poden simular l'ús utilitzant claus dins d'estructures imbricades.

Avantatge: en lloc de tenir conflictes de noms, els objectes permeten mantenir separats diferents conjunts de dades en un sol document.
