Sintaxi d'XML

Anàlisi de codi · Estructura i regles sintàctiques d'XML, problemes dels documents mal formats i espais de noms.

Estructura

L'XML és un llenguatge de marques dissenyat per emmagatzemar i transportar dades. També segueix una estructura jeràrquica amb etiquetes d'obertura i tancament.

Regles sintàctiques

  • Les etiquetes han d'estar correctament tancades.
  • Els elements han d'estar correctament imbricats (no es pot tancar un element abans que l'anterior estigui completament tancat).
  • XML distingeix entre majúscules i minúscules (case-sensitive), és a dir, <titol> i <Titol> són etiquetes diferents.

Problemes dels documents mal formats

Un document XML mal format pot impedir completament que sigui processat, ja que els analitzadors XML (parsers) són molt estrictes.

Conseqüència: l'element <preu> no està correctament tancat amb </preu>, la qual cosa impedirà que el document sigui llegit correctament.

Espais de noms

Els espais de noms en XML són especialment útils quan es combinen dades de diverses fonts.

Avantatge: diferencia elements d'una mateixa estructura que podrien tenir el mateix nom, i evita conflictes en combinar dades.
