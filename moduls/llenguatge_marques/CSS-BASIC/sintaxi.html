Anatomia d'una regla CSS

Un full d'estil és una llista de regles. Cada regla diu a quins elements s'aplica i quins estils reben.

Vocabulari d'una regla
TermeQuè ésA l'exemple
Regla CSSInstrucció que defineix com s'ha d'aplicar un estil a un o més elements HTML.Tot el bloc
SelectorIndica l'element o elements HTML als quals s'aplicaran els estils..element
PropietatLa característica que es vol modificar (color, mida del text, marge...).color
ValorEl valor concret que s'assigna a la propietat.#FFF
DeclaracióParella propietat: valor; dins de la regla.width: 100%;

Les declaracions van entre claus { }, la propietat i el valor se separen amb dos punts : i cada declaració acaba amb punt i coma ;.

Selectors en CSS

Els selectors defineixen quins elements HTML seran afectats per les regles d'estil. Els més comuns en l'aprenentatge bàsic són aquests quatre:

1. Selector de tipus (type selector)

Aplica estils a tots els elements HTML del mateix tipus. Aquest codi posa de color verd tots els títols <h1> de la pàgina.

2. Selector de classe (class selector)

Aplica estils als elements que tenen una classe concreta. S'escriu amb un punt (.) davant del nom. Qualsevol element amb class="la-meva-classe" tindrà fons groc. Una mateixa classe es pot posar a tants elements com calgui.

3. Selector d'id (ID selector)

Aplica estils a un únic element que té un identificador concret. S'escriu amb el símbol de la coixinera (#). Recorda que un id ha de ser únic a la pàgina.

4. Selector universal

El selector universal (*) aplica estils a tots els elements de la pàgina. L'exemple elimina els marges i els farcits de tots els elements, cosa útil per partir d'un estil uniforme. Fixa't que el títol i el paràgraf queden enganxats.

Conceptes importants

Herència

Els elements fills hereten molts estils dels seus pares (per exemple, el color i la font del text). Per això no cal escriure estils per a cada element: si poses el color a body, el h1 ja l'hereta i la segona regla sobra.

Especificitat

Quan dues regles es contradiuen, el navegador aplica la que té més especificitat, és a dir, la que selecciona l'element de manera més precisa. .article .paragraf és més específic que .paragraf, per tant guanya el vermell encara que estigui escrit abans o després.

Com a regla general, de menys a més específic: selector de tipus, selector de classe, selector d'id, estil en línia.

Cascada

Si dues regles tenen la mateixa especificitat, guanya la que s'ha escrit després: tot estil sobreescriu l'anterior. Aquesta és la C de CSS: Cascading, en cascada.

Bones pràctiques

  • Posa noms de classe que expliquin la funció de l'element (.avis, .menu), no el seu aspecte (.vermell, .gros).
  • Prefereix les classes als id per donar estil: es poden reutilitzar i tenen una especificitat més fàcil de controlar.
  • Aprofita l'herència: defineix la font i el color del text a body una sola vegada.
  • Si una regla no s'aplica, comprova l'especificitat i l'ordre de les regles abans de tocar res més.
