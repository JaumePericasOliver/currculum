Media queries

Introducció a les media queries per fer dissenys responsius: @media, min-width, max-width, min-height, orientation i and.

Progrés del bloc

10 / 10

1. Què són les media queries?

Les media queries permeten adaptar el disseny d'una pàgina a les característiques del dispositiu que la mostra: la mida de la pantalla, la resolució o l'orientació. Són la base del disseny responsiu (responsive), que ofereix una bona experiència tant en mòbils com en tauletes i ordinadors.

Una media query és una condició: les regles que hi ha a dins només s'apliquen si la condició es compleix. L'ús més comú és aplicar estils diferents segons l'amplada de la pantalla.

2. Pantalles grans i petites

Un ús típic és tenir un estil per a pantalles grans i un altre per a pantalles petites, amb un punt de tall (breakpoint) a una amplada concreta, per exemple 768 píxels:

Fes la finestra més estreta o més ampla (o obre aquesta pàgina des del mòbil) i observa com canvia la caixa. Aquests apunts també fan servir media queries: si redueixes la finestra, el menú i els marges laterals s'adapten.

3. Condicions més comunes

a) Amplada: min-width i max-width

min-width s'aplica quan la finestra té com a mínim aquesta amplada; max-width, quan en té com a màxim aquesta.

b) Alçada: min-height i max-height

Funcionen igual que les d'amplada, però amb l'alçada de la finestra.

c) Orientació: orientation

Permet aplicar estils diferents si la pantalla està en horitzontal (landscape) o en vertical (portrait).

4. Diverses condicions en una media query

Les condicions es poden combinar amb la paraula clau and: els estils només s'apliquen si es compleixen totes. (També existeix only, que s'escriu davant del tipus de mitjà, com en @media only screen and (min-width: 600px), per evitar que navegadors molt antics apliquin la regla.)

Exemple complet

Una fila de tres elements que en pantalles petites es converteix en una columna.

La metaetiqueta viewport del <head> és imprescindible: sense ella, els mòbils simulen una pantalla d'ordinador i les media queries no funcionen com esperem.

Resum de les propietats vistes
ElementFunció
@mediaDefineix una media query
min-width i max-widthAmplada mínima o màxima de la pantalla
min-height i max-heightAlçada mínima o màxima de la pantalla
orientationOrientació del dispositiu (vertical o horitzontal)
andCombina diverses condicions en una media query

Bones pràctiques

  • Inclou sempre <meta name="viewport" content="width=device-width, initial-scale=1.0">.
  • Escriu primer els estils per a mòbil i afegeix media queries amb min-width per a pantalles més grans (mobile first).
  • Tria els punts de tall segons el teu contingut (quan el disseny es trenca), no segons un model de mòbil concret.
  • Prova la pàgina amb les eines de desenvolupador del navegador, en mode dispositiu.
