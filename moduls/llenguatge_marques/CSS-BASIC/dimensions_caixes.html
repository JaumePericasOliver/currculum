Dimensions i caixes

El model de caixa de CSS, les propietats width i height, box-sizing i el control del desbordament amb overflow.

Progrés del bloc

7 / 10

El model de caixa

CSS considera cada element de la pàgina com una caixa rectangular. Entendre aquest model és important perquè controla com es distribueixen i s'ajusten els elements. La caixa té quatre parts, de dins cap a fora:

  1. Contingut: el contingut real de l'element (text, imatges o altres elements).
  2. Farcit (padding): l'espai entre el contingut i la vora.
  3. Vora (border): el límit al voltant del farcit.
  4. Marge (margin): l'espai exterior entre la vora i els altres elements.

Pots veure un esquema de les quatre parts a l'apunt de marges, farcits i vores.

1. Dimensions: width i height

width (amplada) i height (alçada) defineixen la mida d'un element. Es poden donar en unitats fixes, com píxels (px), o relatives, com percentatges (%), que depenen de la mida del contenidor. El valor auto deixa que el navegador calculi la mida segons el contingut.

2. La propietat box-sizing

Per defecte, width i height només mesuren el contingut: el farcit i la vora s'hi sumen a part. La propietat box-sizing canvia aquest càlcul:

Valors de box-sizing
ValorQuè inclou la midaAmplada real amb l'exemple
content-box (per defecte)Només el contingut; farcit i vora s'afegeixen a part200 + 2·20 + 2·5 = 250 px
border-boxContingut, farcit i vora dins de la mida indicada200 px

Per això molts fulls d'estil (també el d'aquests apunts) comencen amb * { box-sizing: border-box; }: així la mida que escrius és la mida que veus.

3. Desbordament: overflow

Quan el contingut és més gran que les dimensions de l'element, la propietat overflow decideix què passa amb el contingut que sobra:

Valors d'overflow
ValorComportament
visible (per defecte)El contingut que desborda es mostra fora de l'element.
hiddenEl contingut que desborda es retalla i no es veu.
scrollMostra barres de desplaçament, encara que el contingut no desbordi.
autoMostra barres de desplaçament només si el contingut desborda.

Exemple complet

Resum de les propietats vistes
PropietatFunció
width i heightDefineixen les dimensions d'un element
box-sizingDecideix si el farcit i la vora entren dins de les dimensions
overflowControla el contingut que desborda l'element

Bones pràctiques

  • Comença el full d'estil amb * { box-sizing: border-box; } per evitar sorpreses amb les mides.
  • Evita fixar l'alçada (height) d'elements amb text: si el text creix, desbordarà. Deixa-la a auto.
  • Prefereix amplades en % a amplades fixes grans: una caixa de 900 px no cap en un mòbil.
  • Fes servir overflow: auto en lloc de scroll perquè les barres només apareguin quan calen.
