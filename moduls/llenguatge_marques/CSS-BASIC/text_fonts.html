Propietats de text i fonts

Propietats CSS per controlar el text: font-family, font-size, color, text-align, font-weight i font-style.

Controlar el text amb CSS

El CSS permet controlar com es mostren els textos d'una pàgina web. Amb diverses propietats podem canviar la font, el color, l'alineació, la mida del text i altres aspectes visuals per millorar la llegibilitat i l'estètica del contingut.

1. font-family

Defineix el tipus de lletra (tipografia) d'un element. Es poden indicar una o més fonts separades per comes: el navegador aplica la primera que estigui disponible al sistema de l'usuari. Per això l'última sol ser una família genèrica (serif, sans-serif o monospace) que sempre existeix.

Els noms de font que tenen espais s'escriuen entre cometes: "Courier New".

2. font-size

Controla la mida de la lletra. Els valors es poden definir en diverses unitats: píxels (px), ems (em), punts (pt) o percentatges (%).

3. color

Defineix el color del text. Es poden utilitzar noms de colors predefinits, valors en hexadecimal o les funcions rgb() i rgba(). Els veurem amb més detall a l'apunt de colors i fons.

4. text-align

Controla l'alineació del text dins de l'element que el conté.

Valors de text-align
ValorAlineació
leftA l'esquerra
rightA la dreta
centerCentrat
justifyJustificat: les línies ocupen tota l'amplada

5. font-weight

Controla el gruix de la lletra. Els valors més comuns són:

  • normal: valor per defecte.
  • bold: text en negreta.
  • Números entre 100 i 900: 400 equival a normal i 700 a bold.

Si la font no té un gruix concret, el navegador fa servir el més proper que tingui disponible.

6. font-style

Controla l'estil de la font: si el text és normal o en cursiva.

  • normal: text normal.
  • italic: text en cursiva.
  • oblique: text inclinat.

Bones pràctiques

  • Acaba sempre font-family amb una família genèrica (serif, sans-serif o monospace).
  • Defineix la font i la mida base a body i deixa que la resta d'elements l'heretin.
  • Evita el text justificat en columnes estretes: apareixen forats grans entre paraules.
  • Fes servir la negreta i la cursiva amb moderació: si tot destaca, res no destaca.
