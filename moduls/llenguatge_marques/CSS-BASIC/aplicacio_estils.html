Aplicació d'estils

Les tres maneres d'aplicar CSS a un document HTML: estils en línia, estils incrustats i fulls d'estil externs.

Tres maneres d'aplicar CSS

El CSS es pot aplicar a un document HTML de tres maneres principals. Cadascuna té els seus propòsits i usos:

Formes d'aplicar estils
FormaOn s'escriuAbast
En líniaAtribut style de l'etiquetaUn sol element
IncrustatEtiqueta <style> dins del <head>Una sola pàgina
ExternFitxer .css enllaçat amb <link>Totes les pàgines que l'enllacin

1. Estils en línia (inline styles)

Els estils en línia s'apliquen directament a un element HTML, amb l'atribut style dins de la mateixa etiqueta. És adequat per aplicar estils a un sol element de manera ràpida, però no és recomanable per a pàgines grans, ja que dificulta el manteniment.

Estils en línia
AvantatgesInconvenients
Aplicació ràpida i directa a l'element. Dificulta el manteniment en llocs webs grans, perquè caldria aplicar l'estil a cada element manualment.
No aprofita la capacitat de reutilitzar els estils.

2. Estils incrustats (embedded styles)

Els estils incrustats es col·loquen dins de la secció <head> d'un document HTML, dins d'una etiqueta <style>. S'apliquen a tots els elements de la pàgina actual.

Estils incrustats
AvantatgesInconvenients
Més eficient que els estils en línia: es poden aplicar estils a diversos elements d'una mateixa pàgina des d'un sol lloc. Només afecta la pàgina on s'aplica; no es reutilitza entre diverses pàgines.
Si la pàgina creix massa, la lectura i el manteniment es tornen més difícils.

3. Estils externs (external stylesheets)

Els estils externs s'emmagatzemen en un fitxer CSS separat i s'enllacen al document HTML amb l'etiqueta <link> dins de la secció <head>. És el mètode més recomanat per a la majoria de llocs webs, especialment si tenen moltes pàgines.

Estils externs
AvantatgesInconvenients
Permet reutilitzar els estils en diverses pàgines web, facilitant la coherència i el manteniment. Si el fitxer CSS no es carrega correctament (problemes de connexió o d'enllaç), la pàgina es mostrarà sense estils.
Facilita la separació entre el contingut (HTML) i l'estil (CSS).
Optimitza el temps de càrrega: els navegadors poden emmagatzemar el fitxer CSS en memòria cau.

Aquests apunts combinen dues formes: un full d'estil extern comú per a l'aspecte de totes les pàgines i un bloc <style> incrustat a cada pàgina amb els estils dels exemples que només s'utilitzen allà.

Bones pràctiques

  • Fes servir fulls d'estil externs per a tot el lloc web.
  • Reserva els estils incrustats per a regles que només tenen sentit en una pàgina concreta.
  • Evita els estils en línia: barregen contingut i presentació i no es poden reutilitzar.
  • Comprova que la ruta de l'atribut href de <link> és correcta; si no ho és, la pàgina es mostrarà sense estils.
