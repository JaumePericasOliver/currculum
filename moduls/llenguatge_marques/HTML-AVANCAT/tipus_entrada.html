Tipus d'entrada especials

HTML avançat · Tipus d'entrada especials d'HTML5: email, url, tel, number, range, date, time, color, file i més.

Tipus d'entrada d'HTML5

Aquests tipus permeten validar i mostrar els camps de formulari de manera més adequada segons el tipus de dades que esperes obtenir de l'usuari.

Valors de l'atribut type d'input
TipusDada que recull
<input type="password">Contrasenya: amaga els caràcters escrits.
<input type="email">Adreça de correu electrònic.
<input type="url">Adreça web.
<input type="tel">Número de telèfon.
<input type="number">Nombre, amb min, max i step.
<input type="range">Control lliscant entre un mínim i un màxim.
<input type="date">Data.
<input type="time">Hora.
<input type="datetime-local">Data i hora.
<input type="month">Mes i any.
<input type="week">Setmana de l'any.
<input type="color">Selector de color.
<input type="file">Selecció d'un fitxer per carregar.
