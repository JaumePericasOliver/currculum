Contenidors: div, span i center

HTML avançat · Les etiquetes contenidor div i span, i l'etiqueta obsoleta center.

<div>

L'etiqueta <div> (abreviatura de division) s'utilitza per crear contenidors de bloc. És una etiqueta de nivell de bloc: ocupa tot l'ample disponible i comença en una línia nova.

No té significat semàntic en si mateixa; simplement agrupa altres elements i sol ser estilitzada amb CSS. És útil per organitzar i dissenyar diferents seccions d'una pàgina web.

Important: un dels errors més comuns és l'ús excessiu de <div> per a qualsevol cosa quan existeixen etiquetes semàntiques més adequades com <header>, <section>, <article> o <footer>. Utilitza <div> per agrupar elements que formen una unitat lògica o visual només quan no hi hagi una etiqueta semàntica més adequada.

<span>

L'etiqueta <span> és una etiqueta en línia (inline) que serveix per estilitzar o manipular petites porcions de text. A diferència de <div>, no ocupa tot l'ample disponible, sinó només l'espai necessari.

També és una etiqueta no semàntica, usada principalment per aplicar estils o funcionalitat a una part concreta d'un text.

Important:

  • Fes servir <span> per estilitzar text en línia i evita'n l'ús excessiu.
  • Combina <span> amb CSS per mantenir el codi net.
  • Només per a elements en línia: no l'usis per crear contenidors sense necessitat.

<center> (obsoleta)

L'etiqueta <center> s'utilitzava en versions antigues d'HTML per centrar el contingut dins d'una pàgina web, tant text com imatges o altres elements.

Està obsoleta a HTML5 i no s'ha d'utilitzar. Avui dia es fa servir CSS per centrar els elements.
